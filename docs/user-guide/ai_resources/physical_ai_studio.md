# Physical AI Studio
[Physical AI Studio](https://github.com/open-edge-platform/physical-ai-studio) is an end-to-end platform for building embodied-AI and robot-learning workflows. It provides an easy-to-use interface for imitation-learning dataset generation, training, and deployment of Vision-Language-Action (VLA) models.

It streamlines the path from teleoperated demonstrations to trained manipulation policies, so you can capture data, train, and deploy learned robot skills without stitching together bespoke tooling.
