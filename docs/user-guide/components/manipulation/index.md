# Manipulation

The Robotics AI Suite integrates **MoveIt 2** and **MoveIt 2 Servo** on top of
ROS 2 for motion planning and real-time Cartesian control of multi-axis robotic
arms. These capabilities power vision-guided pick-and-place and task execution on
both simulated and physical hardware.

  simulation and physical deployment.
