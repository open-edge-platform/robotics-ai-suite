# ROS

The Robotics AI Suite uses the Robot Operating System 2 (ROS 2) as its primary
middleware and runtime. ROS 2 interconnects sensor ingestion, AI inference,
autonomous navigation, and robotic manipulation into a unified software stack.

Explore the ROS 2 building blocks used across the Suite:

- **[Runtime](../runtime/index.md)** — the ROS 2 execution engine, communication
  model, and lifecycle management.
- **[Navigation](../navigation/index.md)** — Nav2-based autonomous navigation with
  Intel-optimized planning and relocalization components.
- **[Manipulation](../manipulation/index.md)** — MoveIt 2-based motion planning and
  control for robotic arms.
